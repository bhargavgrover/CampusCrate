


## About The Project

**CampusCrate** is a lightweight, responsive Lost & Found board designed specifically for college and university campuses. It allows students, faculty, and campus staff to easily post lost or found items, search by keywords or categories, and reconnect owners with their belongings.

### Key Features
* 🔍 **Smart Search & Filters:** Instantly search items by name, location, or filter by status (Lost, Found, Claimed).
* 🏷️ **Category Chips:** Browse items by category like Electronics, Keys, Accessories, and Clothing.
* 🖼️ **Image Support:** Post items with quick image gallery picks or upload photos directly from your device.
* 📱 **Mobile-Friendly UI:** Designed for smooth use on phones, tablets, and desktop computers.
* ⚡ **Zero Backend Setup:** Runs cleanly as a static web app using browser local storage.
